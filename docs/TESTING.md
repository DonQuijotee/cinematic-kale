当前环境网络已恢复；其他机器需要 NeoForge Maven、Minecraft libraries/metadata/assets 可访问。使用 JDK21 执行 README 中的构建。确认 `BUILD SUCCESSFUL`，检查生成 JAR 仅包含本模组类和资源，不能包含 `dev/dyslexic` 或 `com/github/ysbbbbbb` 的前置类。分别对 CI 0.18.12 与 0.18.28 Beta 重复 clean build 和游戏检查，不要将 Beta 编译成功推断为稳定版成功。

## 砧板单人

1. 放置砧板，用 KC 已存在的切菜配方原料和厨房刀。普通右键仅进入场景，不应消耗原料。
2. 持原料左键一次应恰好使用原配方输入量。切换刀，左键逐次切割，检查原方块进度、声音、耐久、附魔加速。
3. 达到最大次数后再次左键，检查原产物掉落及正常拾取。重复点击不能重复产出。
4. 原料放入但未切时用原版潜行操作退料；切过后不能利用退料复制原料。
5. 空手、错误工具、无配方物品、满背包、创造模式分别与不装本附属的行为对照。
6. 切换配置关闭砧板后重启两端：不应接管普通右键。

## 炒锅（单独打开 pot）

以 KC 的有效热源及配方做完整倒油、投料、锅铲翻炒、合适容器盛菜。比较无热源、已上油、正在烹饪、完成、烧焦、退料情形与原版结果。验证倒油不是每次都重复消耗，动画不自动推进计时或复制菜品。四类手势仍需调试，不算已验收。

## 联机与安全

专用服务器安装三个模组；两个真实客户端分别操作同一设备。记录进度、物品数量、耐久、产出总数。测试其他玩家改变设备后再操作，服务器关闭对应设备时客户端开启仍被拒绝。

测试超距、隔墙、旁观、冒险/无建造权限、出生点保护、领地插件取消事件、连续发送、区块卸载和设备替换。验证跨维度延迟请求被拒绝；同维度重复请求受限流及当前状态校验。需要补充服务端集成测试后再宣称防伪造或多人安全通过。

## 清理与视觉

动作中按 ESC、潜行、移动、被击退、打开背包、切第三人称、死亡、断线、传送、卸载区块、破坏厨具。检查原相机/手臂正常、鼠标可控制、没有隐藏原版手臂或遗留输入锁。验证默认与纤细皮肤、主手左右习惯、低帧率和高延迟。场景结束后 CI 原生工作台仍能进入退出。
